## Latest GitHub Updates

*Sources: [GitHub Blog](https://github.blog/latest/) and [GitHub Changelog](https://github.blog/changelog/) — checked June 2026.*

- **GitHub Agentic Workflows is now in public preview** — automate reasoning-based tasks like issue triage, CI failure analysis, and documentation updates directly in your repository. ([Changelog, Jun 11 2026](https://github.blog/changelog/2026-06-11-github-agentic-workflows-is-now-in-public-preview))
- **Agentic workflows no longer need a PAT** — they now work with the built-in `GITHUB_TOKEN`, removing the need to create and store personal access tokens. ([Changelog, Jun 11 2026](https://github.blog/changelog/2026-06-11-agentic-workflows-no-longer-need-a-personal-access-token))
- **Bot-created pull requests can now trigger CI** — PRs from `github-actions[bot]` can run workflows once a maintainer approves, balancing automation with security. ([Changelog, Jun 11 2026](https://github.blog/changelog/2026-06-11-bot-created-pull-requests-can-run-workflows-if-approved))
- **Copilot CLI gets a unified `/settings` command** — replaces scattered commands like `/theme` and `/streamer-mode` with a single schema-driven configuration home. ([Changelog, Jun 11 2026](https://github.blog/changelog/2026-06-11-copilot-cli-configure-everything-from-one-place-with-settings))
- **Copilot CLI + language servers** — connect a language server to give Copilot CLI real code intelligence for more accurate, context-aware suggestions. ([GitHub Blog, Jun 10 2026](https://github.blog/ai-and-ml/github-copilot/give-github-copilot-cli-real-code-intelligence-with-language-servers/))
- **Copilot code review: new controls** — organizations can now restrict which runners Copilot reviews on, apply content exclusions, and remove the character limit on custom instructions. ([Changelog, Jun 12 2026](https://github.blog/changelog/2026-06-12-copilot-code-review-new-configurations-and-controls))
