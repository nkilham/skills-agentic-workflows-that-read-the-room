## Latest GitHub Updates

*Sources: [github.blog/changelog](https://github.blog/changelog/) — checked June 2026*

- **GitHub Agentic Workflows now in public preview** — Copilot can autonomously handle multi-step tasks (open issues, write code, run tests) directly in your repository. No personal access token required. ([Changelog, Jun 11](https://github.blog/changelog/2026-06-11-github-agentic-workflows-is-now-in-public-preview))
- **Copilot code review gets new controls** — Teams can now configure which files and paths trigger automatic Copilot reviews, giving more precision over the review process. ([Changelog, Jun 12](https://github.blog/changelog/2026-06-12-copilot-code-review-new-configurations-and-controls))
- **Copilot CLI `/settings` command** — All Copilot CLI preferences can now be managed from one place with the new `/settings` slash command. ([Changelog, Jun 11](https://github.blog/changelog/2026-06-11-copilot-cli-configure-everything-from-one-place-with-settings))
- **Bot PRs can run workflows if approved** — Pull requests created by bots can now trigger Actions workflows once a maintainer approves, reducing friction for automated dependency updates. ([Changelog, Jun 11](https://github.blog/changelog/2026-06-11-bot-created-pull-requests-can-run-workflows-if-approved))
- **Discussions manageable from GitHub CLI** — You can now list, view, and create discussions, sub-issues, and issue dependencies directly from `gh` on the command line. ([Changelog, Jun 10](https://github.blog/changelog/2026-06-10-list-view-and-create-discussions-in-github-cli))
- **GitHub Enterprise Server 3.21 GA** — The latest GHES release is generally available with new security and collaboration features. ([Changelog, Jun 11](https://github.blog/changelog/2026-06-11-github-enterprise-server-3-21-is-now-generally-available))
